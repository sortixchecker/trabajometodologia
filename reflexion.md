# 11. Reflexión final
El desarrollo del proyecto hizo posible ver hasta qué punto el control de versiones puede otorgar niveles de organización a un trabajo conjunto. Git, por ejemplo, permite llevar el seguimiento de cada una de las modificaciones que se van haciendo gracias al uso de commits, así como GitHub también permite hacer un seguimiento del trabajo de varias personas con el uso de ramas y Pull Requests.

La experiencia nos hizo ver que una buena organización del repositorio promueve la trazabilidad de los cambios, reduce los errores y potencia la colaboración entre el trabajo de las personas, ya que bien podría decirse que para proyectos académicos como profesionales la experiencia adquirida por muchos y muchos años del desarrollo de la teoría con las ventajas de las formas de trabajo de los desarrolladores.
