# 2. Solución propuesta
Se propone en concreto implementar un flujo de trabajo mediante Git y GitHub para poder gestionar el proyecto de forma ordenada, ya que Git permitirá realizar el registro de cada cambio en un historial de versiones, mientras que GitHub permitirá la colaboración de los participantes mediante ramas independientes y Pull Requests antes de fusionar los cambios a la rama principal del proyecto (GitHub Docs, 2025). La solución consistirá en documentar el proyecto mediante archivos Markdown (.md), consecutivamente hacer cambios mediante commits descriptivos y utilizar ramas independientes para realizar el desarrollo colaborativo.

# 3. Objetivo, alcance y usuarios

## Objetivo
Demostrar el uso adecuado de Git y GitHub mediante el desarrollo de un proyecto conceptual que evidencie el manejo del control de versiones y el trabajo colaborativo.

## Alcance
El proyecto comprende únicamente la documentación del problema, la planificación, los requisitos, la colaboración entre dos participantes y la administración del repositorio utilizando Git y GitHub. No contempla el desarrollo de una aplicación funcional.

## Usuarios
* Estudiante desarrollador.
* Compañero colaborador.
* Docente evaluador.
